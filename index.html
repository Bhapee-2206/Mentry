DETAILED CURRICULUM

Comprehensive Course Syllabus

Structured week-by-week curriculum built around practical application, problem solving, and in-person review.

Module 1: Programming Foundations & Java Syntax

Weeks 1–3

Introduction to JDK, JVM, variables, primitive types, conditional operators, loops (for, while, do-while), methods, array basics, and writing clean console programs.

Module 2: Object-Oriented Programming (OOP)

Weeks 4–7

Classes, objects, constructors, encapsulation, getters/setters, inheritance, polymorphism, abstract classes, interfaces, method overriding, and packages.

Module 3: Exception Handling & Collections Framework

Weeks 8–10

Try-catch-finally, custom exceptions, ArrayList, LinkedList, HashSet, HashMap, iterators, comparator vs comparable, and file I/O operations.

Module 4: Database Integration & Final Project

Weeks 11–14

Relational SQL databases (MySQL/PostgreSQL), tables, keys, CRUD operations, JDBC drivers, PreparedStatement, and full-stack project development.

Module 1: Python Programming for Data Science

Weeks 1–3

Python syntax, functions, data structures (lists, tuples, dicts), comprehension, file parsing, and writing reusable modular scripts.

Module 2: Scientific Libraries (NumPy, Pandas & Matplotlib)

Weeks 4–7

Multi-dimensional arrays with NumPy, tabular data manipulation with Pandas, missing value imputation, statistical summaries, and exploratory charting with Matplotlib/Seaborn.

Module 3: Core Machine Learning Algorithms

Weeks 8–11

Supervised learning concepts, train/test splitting, Linear Regression, Logistic Regression, Decision Trees, Random Forests, and cross-validation with Scikit-Learn.

Module 4: Model Evaluation & Capstone Project

Weeks 12–14

Confusion matrix, precision, recall, F1-score, ROC-AUC, hyperparameters tuning, model serialization (pickle/joblib), and end-to-end predictive pipeline capstone.

CLEAR ANSWERS

Frequently Asked Questions

Details about program schedules, weekly offline hub visits, and prerequisites.

1. Who can join these programs? expand_more
Our programs are designed for college students, freshers, aspiring developers, and beginners entering technology. The foundational modules are also suitable for school students in Class 11 and 12 looking to build programming logic early.
2. How are the classes conducted? expand_more
All classes are conducted live online with an experienced instructor. Programs are designed around live interactive learning rather than pre-recorded course libraries, allowing you to ask queries in real time.
3. What is the daily schedule and class duration? expand_more
Classes are currently planned for 5 days a week, with each live class lasting approximately 1 hour. This structured, daily rhythm helps maintain focus and build consistent programming habits without overwhelming college or school schedules.
4. How does the offline doubt-clearing session work? expand_more
In addition to live online lectures during the week, students attend one offline doubt-clearing session each week at our designated Mentry location. You can bring your laptop, sit with mentors, and debug errors face-to-face.
5. Where is the offline training hub located? expand_more
One offline doubt-clearing session each week at our designated Mentry location. Exact location details will be shared during enrollment.
6. What is the fee structure and how do I enroll? expand_more
Exact pricing and batch schedule details are shared during enrollment. You can submit the enquiry form below or click "Talk to Us" to connect with our academic counseling team.
